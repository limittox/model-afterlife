## Return recap and archive

| Option | Description | Selected |
|--------|-------------|----------|
| Recommended causal recap | A non-blocking “Since your last visit” sheet with up to five significance-ranked causal beats, scene/profile links, current situation, dismiss/review/open/jump-live actions, and a finite 30-scene archive. | ✓ |
| Mandatory recap | Require visitors to complete or dismiss a blocking catch-up modal before seeing the live home. | |
| Archive-only return | Skip a generated recap and expect returning visitors to inspect a chronological archive themselves. | |

**User's choice:** Go with recommendation.
**Notes:** The approved path uses an anonymous local last-visit marker and excludes streaks, currencies, absence penalties, and popularity mechanics.

---

## Resident profiles and behavior explanations

| Option | Description | Selected |
|--------|-------------|----------|
| Recommended layered profile | Stable resident URLs with readable biographies, qualitative relationships, and progressive “Behind this behavior” sections separating joke, inspiration, exaggeration, uncertainty, and sources. | ✓ |
| Compact biography | Give each resident a short static biography but no per-behavior evidence or causal relationship history. | |
| Inline live citations | Put detailed historical sourcing directly into speech bubbles and live-scene presentation. | |

**User's choice:** Go with recommendation.
**Notes:** Historical categories remain distinct, sources stay optional but reachable, and relationship state is never presented as game-like numeric affinity.

---

## Mobile presentation

| Option | Description | Selected |
|--------|-------------|----------|
| Recommended scene-first mobile view | Prioritize the current scene and transcript, include a compact static home view, and provide touch-friendly access to residents, recap, archive, sharing, and jump live. | ✓ |
| Scaled desktop map | Shrink the full desktop canvas and preserve camera-driven navigation on narrow screens. | |
| Transcript-only page | Remove all visual establishment and expose only dialogue on mobile. | |

**User's choice:** Go with recommendation.
**Notes:** Mobile remains recognizably the same home but never depends on dragging, precise canvas interaction, or a shrunken desktop layout.

---

## Scene sharing

| Option | Description | Selected |
|--------|-------------|----------|
| Recommended canonical scene page | Stable server-rendered permalinks with canonical scene detail, exact model authorship, historical context, disclosures, original social previews, Web Share, and copy-link fallback. | ✓ |
| Screenshot sharing | Share only a rendered image of the moment, without a durable canonical transcript page. | |
| Transient client route | Link to client state that may disappear or change as the live world advances. | |

**User's choice:** Go with recommendation.
**Notes:** Sharing is account-free and does not create feeds, comments, followers, reactions, or popularity-driven canon. Disclosure and provenance must remain visible in off-site metadata.

---

## Visual identity and accessibility

| Option | Description | Selected |
|--------|-------------|----------|
| Recommended original identity and complete access paths | Keep the compact home structure, replace provisional visuals with an original warm computational-care-home pixel system, and preserve semantic, keyboard, focus, contrast, reflow, pause, and reduced-motion paths. | ✓ |
| Visual reskin only | Improve palette and art while making only minimal accessibility and responsive changes. | |
| Structural rebuild | Replace the established observer hierarchy and home layout before adding return and sharing features. | |

**User's choice:** Go with recommendation.
**Notes:** Resident recognition comes from original silhouettes, clothing, props, and animation language—not provider logos, copied mascots, or protected game assets or expression. Reduced motion removes decorative movement without stopping canonical world time.
